# Magic Balloons — página web

Página hecha con HTML y CSS normales. No hay que instalar nada: abre
`index.html` con doble clic y se ve en el navegador.

## Dónde está cada cosa

| Archivo | Qué contiene |
|---|---|
| `index.html` | Todo el texto, precios, fotos y enlaces |
| `css/styles.css` | Colores, tamaños y acomodo |
| `js/main.js` | El menú en celular y la galería ampliada |
| `images/` | Logo, portada, fotos de paquetes y galería |

## Cambios comunes

**Cambiar un precio.** En `index.html` busca (Ctrl+F) el precio actual, por
ejemplo `$2,499`, y cámbialo. Antes, confirma que en FareHarbor esté igual:
el cliente paga lo que diga FareHarbor, no lo que diga la página.

**Agregar una foto a la galería.** Sube la foto a `images/galeria/`, busca
`GALERÍA` en `index.html`, copia una línea `<img ...>` y cambia el nombre del
archivo y el texto de `alt`.

**Cambiar un color.** Los colores de la marca están anotados al inicio de
`css/styles.css`. Busca el código (por ejemplo `#e8590c`) y reemplázalo.

**Si algo se rompe.** Cada cambio queda guardado en el historial, así que
siempre se puede regresar a la versión anterior.
